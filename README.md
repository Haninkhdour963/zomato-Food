This project replicates Zomato’s homepage UI, enabling users to explore restaurants, popular categories, curated collections, and download the mobile app.

## Project Description

This project is a **restaurant discovery and food delivery platform** inspired by Zomato. It allows users to find the best dining options in their city, including restaurants, cafes, and more. The platform features detailed menus, user reviews, and high-quality images to enhance the user dining experience.

Key capabilities include:

- **Restaurant Discovery:** Browse a wide variety of restaurants and cafes tailored to user preferences.  
- **User Reviews:** Read and contribute reviews to help users make informed dining decisions.  
- **Menu Exploration:** View detailed menus and images of dishes before visiting.  
- **Location-Based Search:** Discover dining options based on current location.  
- **Responsive Design:** Optimized for both desktop and mobile devices ensuring seamless accessibility.

---

## Features

- Responsive, dark-themed **navbar** with logo and navigation links  
- Hero section with location dropdown and search bar  
- Popular food **categories** displayed with images and descriptions  
- Curated **collections** of restaurants with pagination controls  
- Listing of popular localities with restaurant counts  
- App download section with email/phone input for sharing app links  
- Accordion sections to explore cuisines, restaurant types, top chains, and delivery cities  
- Informative footer with company info, help center, exploration links, and social media
